## Description (893/4000)
```
Plekioは治療を続けるためのお薬管理アプリです。服薬コースを計画し、飲む時間になると通知でお知らせ。アプリ、ロック画面、ウィジェット、Siriからワンタップで記録できます。

データはすべてiPhoneの中だけに保存。アカウントもサーバーも分析ツールもありません。

今日の予定をひと目で
・その日の服用を朝・昼・夜にまとめて表示
・「次の服用」カードで、その時間の薬をまとめて記録
・記録はいつでも取り消し可能
・1日を達成すると、まとめと連続記録を表示

治療コース
・用量、服用時間、N日ごとのスケジュール、開始日と終了日
・食前・食事中・食後・空腹時を設定
・在庫を管理し、なくなる前にお知らせ
・終了したコースは履歴へ。新しい日付で数秒で再開
・旅行中も、08:00の薬は時差のある場所でも08:00のまま

頼れるリマインダー
・通知から直接「服用」「スヌーズ」「スキップ」
・アプリアイコンのバッジで未記録の服用がわかる
・日記・血圧・在庫不足のリマインダーも設定可能

体調日記
・気分、エネルギー、不快感、睡眠、水分、症状、達成したこと
・経過写真を並べて比較
・血圧と脈拍をグラフで表示

医師へのレポート
服用状況・体調・血圧を好きな期間でPDFにまとめ、受診前に共有できます。

ウィジェットとSiri
・ホーム画面とロック画面のウィジェット：次の服用、今日の進捗、今日、在庫が少ない、日記、血圧
・ウィジェットから服用や今日の気分を直接記録
・「Plekioで薬を記録」「Plekioで次の薬を教えて」「Plekioで血圧を記録」と話しかけるだけ

プライバシーを最優先
・データはデバイス内だけに保存
・Face ID、Touch ID、パスコードでアプリをロック
・iPhoneのロック中はウィジェットの詳細を非表示

iPhoneとiPadに対応。ライト／ダークモード、Dynamic Type、VoiceOverをサポート。

Plekioは記録のためのツールであり、医学的なアドバイスを提供するものではありません。必ず医師の指示に従ってください。
```
